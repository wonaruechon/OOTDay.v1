🚀 Quick Start Guide

  • Set up your API key
    Add OPENROUTER_API_KEY=your-key to .env.local file
  • Start the development server
    Run pnpm dev in the v0-ootd-ay-ai-fashion-assistant directory
  • Import the component
    Use MultiPanelTestMode component in your chat interface
  • Select models and scenario
    Choose up to 4 different models and a test scenario
  • Run tests and compare
    Click "Run All Tests" to execute in parallel and view results
  • Export results
    Click "Export All" to download results in Markdown and CSV formats

🔧 Component Integration

To integrate the Multi-Panel Test Mode into your application: 

import { MultiPanelTestMode } from '@/components/chat/MultiPanelTestMode';
import { exportResultsBoth } from '@/lib/test-result-exporter';

function YourPage() {
  const handleExport = (results) => {
    exportResultsBoth(results);
  };

  return (
    <MultiPanelTestMode
      onExportAll={handleExport}
      maxPanels={4}
    />
  );
}
