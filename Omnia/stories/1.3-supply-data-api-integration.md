# Story 2.3: Supply Data API Integration

**Epic:** Epic 2 - Core Supply Data Display & Filtering

## User Story

**As a** developer,
**I want** to integrate with Manhattan Active™ supply data API,
**so that** the application can fetch and display real-time inventory data.

## Acceptance Criteria

1. API service module created for supply data endpoints
2. API client configured with base URL ~~and authentication headers~~ (authentication out of scope)
3. GET endpoint `/api/supply-details` integrated with query parameters:
   - locationId
   - itemId
   - supplyTypeId
   - view
   - includeErrored
   - displayPendingReview
   - page
   - pageSize
4. React Query hook implemented for data fetching with caching
5. Loading state displays spinner during API calls
6. Error state displays error message with retry option
7. API response data mapped to TypeScript interfaces
8. Pagination parameters included in API request
9. API client includes retry logic for transient failures
10. Request timeout configured (e.g., 30 seconds)

## Related Requirements

- NFR10: Manhattan Active™ Omni APIs integration (RESTful)
- NFR1: Load 10,000 records with pagination within 3 seconds
- Technical Assumption: Axios or Fetch API with retry logic
- Technical Assumption: React Query for server state management

## Dependencies

- ~~Story 1.2 (Authentication for API auth headers)~~ **OUT OF SCOPE** - API will be accessed without authentication for this release
- Story 2.1 (Filter controls to pass query parameters)
- Story 2.2 (Dropdown selectors for view parameter)

## Notes
