# 🚀 OOTDay Quick Start Guide

## ⚡ 60-Second Setup

### Run the Demo
```bash
cd /Users/naruechon/Documents/Project/ChatDialog/t7
python3 main.py
```

### Interactive Chat
```bash
python3 chat_cli.py
```

### Run Tests
```bash
python3 main.py test
```
